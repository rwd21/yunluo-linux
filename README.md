# Yunluo Linux

Native Arch Linux OS for Redmi Pad (Yunluo) tablet.

This project aims to bring native Linux support to the Xiaomi Redmi Pad tablet, allowing you to run Arch Linux ARM directly on the hardware.

## Status

🚧 Project is under initial development.

## Device Information

- **Device**: Xiaomi Redmi Pad
- **Codename**: yunluo
- **SoC**: MediaTek Helio G99 (MT6789)
- **Architecture**: ARM64 (aarch64)
